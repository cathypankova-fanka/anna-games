# anna.games

Зеркало «Анюткиной игры» на домене https://anna.games.

Код игры живёт в [cathypankova-fanka/zuba-slonya](https://github.com/cathypankova-fanka/zuba-slonya)
(там же сайт https://cathypankova-fanka.github.io/zuba-slonya/). Этот репозиторий только собирает
ту же игру для корня домена и выкладывает её на GitHub Pages с адресом anna.games.
Проверка новых версий — каждые 15 минут (или вручную: Actions → Deploy anna.games → Run workflow).
